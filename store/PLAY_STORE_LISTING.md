## Full Description

Type Like a Human, Not a Machine.

Human Typing is a privacy-first keyboard that types your clipboard with a natural, human rhythm. It's more than a keyboard—it's a complete input toolkit designed for privacy, productivity, and accessibility.

Why Human Typing?

• Human-Cadence Typing: Break the robotic paste. Our engine types text character-by-character with natural pacing, pauses, and even occasional corrections.

• 100% On-Device Privacy: Your data never leaves your phone. No servers, no tracking, no analytics. The vault is encrypted with Android Keystore and gated by biometrics. Cloud backup is disabled.

• Accessibility First: Designed for users with motor impairments, RSI, or chronic pain. Features like Slow Keys, Bounce Keys, and text-to-speech feedback make typing easier and more comfortable.

• Productivity Powerhouse: Searchable clipboard history, smart templates with variables, and on-device AI rewriting help you work faster.

Key Features:

✍️ Human-Cadence Typing
• Types clipboard content with human-like speed and rhythm
• Pause and resume typing from any character
• Backspace with single-tap or long-press for word/field deletion

🔒 Encrypted Vault
• Automatically detects and secures passwords, credit cards, OTPs, and API keys
• Encrypted with AES-256-GCM using a key stored in the Android Keystore, gated by biometric authentication
• Auto-purges sensitive data from the system clipboard

🎤 Voice Input
• Hold to speak and release to transcribe
• Requests on-device recognition wherever the device supports it
• The app itself never records or stores your audio

📋 Smart Clipboard Manager
• Searchable history with tags, pins, and todo lists
• Manually save snippets for quick access
• Clear history without losing pinned items

📝 Templates with Variables
• Create reusable messages with {name}, {topic}, etc.
• Trigger with ::template_name or via the picker
• Perfect for sales, support, and customer service

🤖 On-Device AI Rewriting (Optional)
• Rewrite drafts as Professional, Friendly, Shorter, Longer, or Rephrased
• Powered by Gemini Nano on supported devices—no cloud processing
• Or use the standalone rewrite screen: review the result before you copy it

♿ Accessibility Features
• Focus Mode: Simplified layout with larger keys
• Slow Keys: Prevents accidental input from tremors
• Bounce Keys: Ignores rapid, repeated keypresses
• Text-to-Speech: Speaks characters aloud as you type

🔏 Proof-of-Human Typing Signature (Advanced)
• Generates a cryptographic signature based on your typing rhythm
• Can be embedded invisibly in messages to verify human authorship
• For B2B and platform integration (licensable)

Designed for Everyone

Whether you're a professional with RSI, a developer who needs to paste code with human timing, or someone who just wants a private keyboard that doesn't track everything you type—Human Typing is for you.

No Ads. No Tracking. No Compromises.

Your keyboard should be private. Human Typing is built from the ground up with privacy as the default.
